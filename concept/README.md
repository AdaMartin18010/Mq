# concept/ 2.0 人类友好总集

> **定位**: 项目主人确认，concept/ 升级为「导览+内容兼顾」的人类最友好入口。
> 原始 `concept01~06.md` 仍作为历史资产冻结；新总集不替代 `topics/` 的权威定义，而是给出阅读地图、论证导航与快速入口。

## 为什么保留 concept/

`topics/` 已经覆盖了 200+ 篇深度文档，但人类第一次进入知识库时，往往不知道从哪读起。
concept/ 2.0 的任务是：**用 30 分钟建立全局感，再决定往哪个旗舰文档深钻**。
它不负责“最权威”，只负责“最友好”；权威定义、形式化推导与实测细节都在 `topics/` 与 `Testing/`。

## 使用纪律

1. **概念定义以 01-58 为准**：本目录的“人话版”是直觉解释，正式定义、反例与关系仍看 01-58。
2. **事实陈述看 P3 标注**：【定理】/【论证】/【估算】的用法见 `00-论证标准导论.md`。
3. **图解层与机读层互补**：图解回答“为什么”，机读层回答“能不能被工具验证”。
4. **场景落地走 03**: 具体业务场景先查 `03-场景论证链.md`，再按链补 Testing/06 用例。
