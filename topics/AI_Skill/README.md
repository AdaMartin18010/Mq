## 与国际标准的对齐关系

本系列对齐 [agentskills.io](https://agentskills.io/) 发布的 Agent Skills 开放规范（2025-12-18 发布，2026-10-22 捐赠给 Linux 基金会旗下的 Agentic AI Foundation）。规范事实以 AI_SKILL-01 为准（核实至 2026-11）；本目录的制作规范（AI_SKILL-03）是项目层约束，不得与开放规范冲突，冲突时以开放规范为准并回写修订。

## 使用建议

- **想给项目做技能化改造**：先读 AI_SKILL-02（图谱）→ AI_SKILL-03（规范）→ AI_SKILL-04（模板）
- **想直接使用技能**：读 AI_SKILL-05（安装与用例）
- **想核实标准事实**：读 AI_SKILL-01（所有版本事实附来源链接）
