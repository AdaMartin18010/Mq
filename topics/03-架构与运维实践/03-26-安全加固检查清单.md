## 3.26.1 认证授权

### Kafka 安全检查

- [ ] 启用 SASL 认证（`sasl.mechanism=PLAIN/GSSAPI/SCRAM`）
- [ ] 配置 ACL 授权（`authorizer.class.name=kafka.security.authorizer.AclAuthorizer`）
- [ ] 禁用匿名访问（`allow.everyone.if.no.acl.found=false`）
- [ ] 定期轮换密码（建议 ≤ 90 天）
- [ ] 按 Topic/ConsumerGroup 实施最小权限原则

### NATS 安全检查

- [ ] 配置用户名/密码或 NKey/Token 认证
- [ ] 启用权限规则（`permissions` 块）限制发布/订阅主题
- [ ] 限制单用户连接数
- [ ] 监控异常连接与失败登录
- [ ] 禁用无认证模式部署

### RabbitMQ 安全检查

- [ ] 创建专用业务用户，删除默认 `guest` 用户或限制其访问
- [ ] 配置用户权限（`configure/write/read`）
- [ ] 设置虚拟主机隔离（vhost per tenant）
- [ ] 启用管理界面 HTTPS
- [ ] 定期审计用户与权限

安全配置模板参考 [`topics/config-templates/security-enhanced-config.properties`](../config-templates/security-enhanced-config.properties)：

```properties
# Kafka SASL_SSL 示例
kafka.security.protocol=SASL_SSL
kafka.sasl.mechanism=PLAIN
kafka.authorizer.class.name=kafka.security.authorizer.AclAuthorizer
kafka.allow.everyone.if.no.acl.found=false

# NATS TLS + 认证
nats.tls.enabled=true
nats.auth.enabled=true
nats.auth.user=admin
nats.auth.password=admin-secret

# RabbitMQ 安全
rabbitmq.ssl.enabled=true
rabbitmq.auth.default_user=admin
rabbitmq.auth.password_hashing.algorithm=sha256
```

## 3.26.2 加密传输

### TLS/SSL 配置

- [ ] 启用 TLS/SSL（端口 9093 for Kafka，5671 for RabbitMQ）
- [ ] 使用有效且未过期的证书
- [ ] 配置完整证书链
- [ ] 禁用弱加密算法（TLS 1.0/1.1、RC4、DES）
- [ ] 启用证书双向认证（mTLS）对高敏感场景

### 证书管理

- [ ] 证书有效期监控，到期前 30 天告警
- [ ] 证书自动续期（如 Let's Encrypt + cert-manager）
- [ ] 私钥安全存储（HSM/Vault/KMS）
- [ ] 证书撤销列表（CRL）或 OCSP 检查

## 3.26.3 网络安全

### 网络隔离

- [ ] 消息集群部署于内网/VPC
- [ ] 配置防火墙规则，仅开放必要端口
- [ ] 限制访问源 IP（安全组/ACL）
- [ ] 管理面与数据面分离

### 端口管理

| 系统 | 数据端口 | 管理/监控端口 | 建议操作 |
| ------ | --------- | -------------- | --------- |
| **Kafka** | 9092（PLAINTEXT）/9093（SASL_SSL） | 9094（Controller）、JMX | 关闭 9092 若启用 SASL_SSL |
| **NATS** | 4222 | 8222（HTTP 监控）、6222（路由） | 限制 8222 仅监控网络可访问 |
| **RabbitMQ** | 5672（AMQP）/5671（AMQPS） | 15672（管理界面）、25672 | 管理界面禁止公网暴露 |

## 3.26.4 数据安全

### 数据保护

- [ ] 敏感消息字段加密（应用层 AES-256-GCM 或字段级加密）
- [ ] 静态数据加密（磁盘加密/存储加密）
- [ ] 定期备份数据，备份文件加密
- [ ] 数据访问审计

### 数据清理

- [ ] 设置数据保留策略（Kafka `retention.ms/retention.bytes`）
- [ ] 定期清理旧数据
- [ ] 安全删除数据（覆盖或加密销毁）
- [ ] 建立数据销毁流程

---

## 3.26.5 审计日志

### 日志记录

- [ ] 启用操作日志（认证、授权、配置变更）
- [ ] 记录访问日志（客户端 IP、用户、Topic/Queue）
- [ ] 记录错误日志与异常行为
- [ ] 日志集中存储（ELK/Loki/Splunk）
- [ ] 日志定期归档，保留 ≥ 90 天

### 日志分析

- [ ] 配置异常行为检测（如暴力破解、越权访问）
- [ ] 安全事件实时告警
- [ ] 每月定期审计分析
- [ ] 合规性检查（等保/GDPR/PCI-DSS）

## 3.26.6 安全审计脚本

使用项目提供的安全审计脚本 [`topics/scripts/security-audit-enhanced.sh`](../scripts/security-audit-enhanced.sh) 执行自动化检查：

```bash
# 生成安全审计报告
bash topics/scripts/security-audit-enhanced.sh security-audit-report-$(date +%Y%m%d).txt
```

该脚本会检查：

- Kafka `server.properties` 中 SASL/SSL/ACL 配置
- RabbitMQ 默认用户存在情况
- 通用安全建议清单

### 安全加固总检查清单

- [ ] 认证已启用，匿名与默认账号已禁用/限制
- [ ] TLS 已启用，证书有效期 ≥ 30 天
- [ ] ACL/RBAC 授权已配置
- [ ] 管理界面不暴露公网
- [ ] 审计日志已开启并集中存储
- [ ] 数据保留与清理策略已生效
- [ ] 每季度执行一次安全审计脚本
- [ ] 密钥与证书轮换周期 ≤ 90 天
