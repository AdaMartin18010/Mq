## 3.32.1 审计范围与周期

安全审计覆盖消息队列系统的认证、授权、加密、网络、日志与配置变更六个维度。建议按以下周期执行：

| 审计类型 | 频率 | 覆盖范围 | 输出物 |
| ---------- | ------ | ---------- | -------- |
| 日常巡检 | 每日 | 失败登录、异常连接、证书有效期 | 巡检日报 |
| 月度审计 | 每月 | ACL/权限、TLS 配置、补丁版本 | 审计报告 |
| 季度审计 | 每季度 | 全量配置、日志留存、变更记录 | 季度合规报告 |
| 事件审计 | 触发式 | 安全事件、入侵疑似、配置漂移 | 事件报告 |

审计范围应覆盖以下六大维度：

1. **认证授权**：SASL/用户名密码/Token、ACL/RBAC、匿名访问禁用、最小权限原则。
2. **加密传输**：TLS/SSL  listener、证书链、弱算法禁用、证书有效期。
3. **网络安全**：防火墙规则、安全组、端口最小化、内网/VPC 隔离。
4. **数据安全**：存储加密、敏感字段脱敏、备份加密、数据销毁流程。
5. **审计日志**：操作日志、访问日志、配置变更日志、日志集中存储与防篡改。
6. **漏洞与补丁**：CVE 扫描结果、当前运行版本、关键补丁安装情况。

## 3.32.2 审计准备

执行审计前需准备：

1. 当前运行组件清单（Broker、Schema Registry、ZooKeeper/KRaft、Proxy、控制台）。
2. 配置文件路径与读取权限（`server.properties`、`nats-server.conf`、`rabbitmq.conf` 等）。
3. 管理命令行工具（`kafka-acls.sh`、`rabbitmqctl`、`nats-server -t`）。
4. 日志聚合系统查询权限（Loki、ELK、Splunk 等）。
5. 上一周期审计报告与未关闭问题清单。

## 3.32.3 自动化审计脚本

项目已提供自动化审计脚本，可直接执行并生成报告。

```bash
# 基础版安全审计（Kafka/NATS/RabbitMQ 三选一或全部）
# 用法: scripts/security-audit.sh [kafka|nats|rabbitmq|all] [output_file]
cd E:/_src/Mq/topics
bash scripts/security-audit.sh all security-audit-2026-11.txt

# 增强版安全审计（含配置扫描与安全建议）
bash scripts/security-audit-enhanced.sh security-audit-report-2026-11.txt
```

输出示例（节选）：

```text

--- NATS安全审计 ---
✅ TLS加密已启用
✅ 认证已配置

--- RabbitMQ安全审计 ---
⚠️  发现默认用户: guest

--- 安全建议 ---
1. 启用TLS/SSL传输加密

3. 启用访问控制（ACL/RBAC）
4. 定期更新密钥和证书
5. 启用审计日志
```

## 3.32.4 Kafka 安全审计

### 配置检查命令

```bash
# 1. 检查 SASL/SSL/ACL 关键参数
KAFKA_HOME=${KAFKA_HOME:-/opt/kafka}
grep -E "sasl|ssl|authorizer|security.inter.broker.protocol" \
  $KAFKA_HOME/config/server.properties

# 2. 列出全部 ACL 规则
kafka-acls.sh --bootstrap-server localhost:9092 \
  --command-config admin.properties --list

# 3. 检查是否允许匿名访问（应为 false 或未设置）
grep "allow.everyone.if.no.acl.found" $KAFKA_HOME/config/server.properties

# 4. 查看 broker 版本与补丁
kafka-broker-api-versions.sh --bootstrap-server localhost:9092 | head -5
```

### Kafka 审计要点

| 检查项 | 期望状态 | 不通过风险 |
| -------- | ---------- | ------------ |
| `sasl.enabled.mechanisms` 已配置 | PLAIN/SCRAM-SHA-512/GSSAPI 至少一个 | 匿名访问风险 |
| `ssl.keystore.location` 已配置 | 指向有效 JKS/PEM 文件 | 传输明文暴露 |
| `authorizer.class.name` 已配置 | `AclAuthorizer` 或 `StandardAuthorizer` | 无 ACL 控制 |
| `allow.everyone.if.no.acl.found=false` | 显式禁用 | ACL 宽松回退 |
| 证书有效期剩余 | ≥30 天 | 服务中断风险 |
| Broker 版本 | 运行版本 ≥组织基线 | CVE 未修复 |

## 3.32.5 NATS 安全审计

### 配置检查命令

```bash
# 1. 验证配置文件语法并查看生效参数
nats-server -t -c nats-server.conf

# 2. 检查 TLS 与认证配置
grep -E "tls {|authorization|accounts|users" nats-server.conf

# 3. 检查连接与订阅数限制
grep -E "max_connections|max_subscriptions|max_payload" nats-server.conf

# 4. 使用 nats-cli 检查账户/用户列表（需管理员凭据）
nats --server nats://localhost:4222 --user admin --password xxx server report accounts
```

### NATS 审计要点

| 检查项 | 期望状态 | 不通过风险 |
| -------- | ---------- | ------------ |
| `tls {}` 块存在 | cert_file/key_file/ca_file 有效 | 传输明文暴露 |
| `authorization` 或 `accounts` 已配置 | 至少启用用户名/密码或 Token | 未授权访问 |
| `max_connections` 已设置 | 按租户/业务设定上限 | 资源耗尽 DoS |
| `allow_non_tls` 未启用 | 无或 false | TLS 降级攻击 |
| 证书有效期剩余 | ≥30 天 | 服务中断风险 |

## 3.32.6 RabbitMQ 安全审计

### 配置检查命令

```bash
# 1. 列出用户与角色
rabbitmqctl list_users

# 2. 列出虚拟主机与每个 vhost 的权限
rabbitmqctl list_vhosts
rabbitmqctl list_permissions -p /

# 3. 检查 SSL 与高级配置
rabbitmqctl environment | grep -i ssl

# 4. 检查默认 guest 用户是否已删除或禁用
rabbitmqctl list_users | grep guest
```

### RabbitMQ 审计要点

| 检查项 | 期望状态 | 不通过风险 |
| -------- | ---------- | ------------ |
| `guest` 用户已删除/禁用 | 无默认高权限账号 | 默认口令攻击 |
| SSL listener 已启用 | `listeners.ssl.default=5671` | 传输明文暴露 |
| 虚拟主机按业务隔离 | 每个租户/业务独立 vhost | 越权访问 |
| 用户权限遵循最小权限 | configure/read/write 按需授予 | 越权操作 |
| 插件只启用必要项 | 关闭 management 外不必要的插件 | 攻击面扩大 |

## 3.32.7 审计报告与跟踪

审计报告应至少包含以下内容：

1. **执行摘要**：审计范围、时间、参与人、整体风险等级（高/中/低）。
2. **发现清单**：问题描述、涉及组件、风险等级、复现命令或配置截图。
3. **改进建议**：每项建议须指定责任人与计划完成时间。
4. **跟踪验证**：修复后复测，并保留复测命令与输出。

建议使用脚本输出文件作为附件，并在问题跟踪系统中创建工单。对于高优先级问题，应在 7 个工作日内完成修复与复测【估算】。

## 3.32.8 安全审计检查清单

- [ ] 已确认本次审计范围、目标系统与版本基线。
- [ ] 已执行 `scripts/security-audit.sh all` 或 `scripts/security-audit-enhanced.sh` 并保存报告。
- [ ] Kafka：`sasl.enabled.mechanisms` 已配置且 `authorizer.class.name` 非空。
- [ ] Kafka：`ssl.keystore.location` 与 `ssl.truststore.location` 指向有效文件，证书有效期 ≥30 天。
- [ ] Kafka：`allow.everyone.if.no.acl.found=false` 或等效禁用。
- [ ] NATS：`tls {}` 块完整且 `allow_non_tls` 未启用。
- [ ] NATS：`authorization` 或 `accounts` 已配置，禁止匿名连接。
- [ ] RabbitMQ：`guest` 用户已删除或权限最小化。
- [ ] RabbitMQ：SSL listener 启用且虚拟主机按业务隔离。
- [ ] 所有组件日志已集中收集，保留时间 ≥90 天【估算】。
- [ ] 已记录高/中风险问题并创建修复工单，明确责任人与完成时间。
- [ ] 修复完成后已复测并通过审计脚本验证。
