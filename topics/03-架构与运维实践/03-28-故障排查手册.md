## 3.28.1 常见故障类型

### 故障分类

1. **连接故障**
   - 无法连接服务器
   - 连接超时或断开
   - 认证失败

2. **性能故障**
   - 吞吐量下降
   - 延迟增加
   - 资源耗尽（CPU/内存/磁盘）

3. **数据故障**
   - 消息丢失
   - 消息重复
   - 消费积压

## 3.28.2 Kafka 故障排查

### 连接问题

```bash
# 检查 Broker API 版本与连通性
kafka-broker-api-versions.sh --bootstrap-server localhost:9092

# 检查网络连接
telnet localhost 9092

# 查看 Broker 日志
tail -f /var/log/kafka/server.log

# 检查 ZooKeeper/KRaft 元数据状态
kafka-metadata-quorum.sh --bootstrap-server localhost:9092 describe --status
```

常见原因：

- `advertised.listeners` 配置错误导致客户端无法解析
- SASL/SSL 认证或证书异常
- ZooKeeper/KRaft 元数据不一致

### 性能问题

```bash
# 检查 Topic 分区与副本状态
kafka-topics.sh --bootstrap-server localhost:9092 --describe --topic my-topic

# 检查消费组延迟
kafka-consumer-groups.sh --bootstrap-server localhost:9092 --group my-group --describe

# 检查磁盘 IO
iostat -x 1 5

# 检查网络延迟
ping -c 10 <broker-ip>
```

常见原因：

- 单分区热点导致消费者无法并行
- `replica.lag.time.max.ms` 设置过小触发 ISR 频繁收缩
- 磁盘 IO 饱和或网络延迟高

## 3.28.3 NATS 故障排查

### 连接问题

```bash
# 检查 Server 状态
curl http://localhost:8222/varz

# 检查端口监听
ss -tuln | grep 4222

# 查看日志
journalctl -u nats-server -f

# 检查路由连接（集群模式）
curl http://localhost:8222/routez
```

常见原因：

- 客户端配置单点地址，未配置多 server 列表
- TLS/认证配置不匹配
- 集群路由端口 6222 网络不通

### 性能问题

```bash
# 检查连接数与内存
curl -s http://localhost:8222/varz | jq '.connections, .mem'

# 检查慢消费者数量
curl -s http://localhost:8222/varz | jq '.slow_consumers'

# 检查 JetStream 流与消费者状态
nats stream info my-stream
nats consumer info my-stream my-consumer
```

常见原因：

- 慢消费者导致消息堆积
- `max_payload` 过小或过大
- JetStream 存储目录磁盘 IO 瓶颈

## 3.28.4 RabbitMQ 故障排查

### 连接问题

```bash
# 检查节点状态
rabbitmqctl status

# 检查端口监听
ss -tuln | grep 5672

# 查看日志
tail -f /var/log/rabbitmq/rabbit@*.log

# 检查用户与权限
rabbitmqctl list_users
rabbitmqctl list_permissions
```

常见原因：

- 用户权限或 vhost 配置错误
- 管理插件未启用或端口冲突
- Erlang cookie 不一致导致集群节点无法通信

### 性能问题

```bash
# 检查队列积压
rabbitmqctl list_queues name messages messages_ready messages_unacknowledged

# 检查连接与通道数
rabbitmqctl list_connections
rabbitmqctl list_channels

# 检查内存与磁盘告警
rabbitmqctl status | grep -E "memory|disk"
```

常见原因：

- 队列无消费者或 `prefetch_count` 过小
- 镜像队列同步延迟
- 内存/磁盘告警触发流控

### 故障现象速查表

| 现象 | 优先检查命令 | 常见根因 | 下一步动作 |
| ------ | ------------- | --------- | ----------- |
| **无法连接** | `telnet <host> <port>` | 防火墙/监听器配置错误 | 检查 `advertised.listeners`/安全组 |
| **消费延迟高** | `kafka-consumer-groups.sh --describe` | 分区不足/消费慢 | 扩容消费者或优化处理逻辑 |
| **磁盘告警** | `df -h` / `iostat` | 保留策略不足/消息突增 | 扩容磁盘或缩短保留周期 |
| **内存不足** | `free -m` / `rabbitmqctl status` | 队列积压/连接过多 | 限流或扩容节点 |
| **节点频繁掉线** | `curl http://nats:8222/routez` | 网络抖动/路由配置错误 | 检查集群路由与网络延迟 |

## 3.28.5 故障排查流程

### 排查步骤

1. **收集信息**
   - 记录故障现象、影响范围、发生时间
   - 收集错误日志与系统指标
   - 确认最近变更（发布、配置、扩容）

2. **定位问题**
   - 按连接→性能→数据的顺序分层排查
   - 使用项目脚本 [`topics/scripts/troubleshoot.sh`](../scripts/troubleshoot.sh) 快速扫描：

```bash
# 全系统扫描
bash topics/scripts/troubleshoot.sh all

# 仅 Kafka
bash topics/scripts/troubleshoot.sh kafka
```

1. **解决问题**
   - 执行修复操作
   - 验证恢复
   - 记录处理过程

## 3.28.6 排查检查清单

- [ ] 网络连通性正常（`telnet`/`curl`/`ping`）
- [ ] 服务进程运行且端口监听正常
- [ ] 认证/授权/证书配置正确
- [ ] 磁盘使用率 < 75%，内存使用率 < 80%
- [ ] 消费延迟/lag 在正常基线范围内
- [ ] 日志中无持续 ERROR/FATAL
- [ ] 最近变更已回滚或验证无影响
- [ ] 已使用 `troubleshoot.sh` 执行自动化扫描
