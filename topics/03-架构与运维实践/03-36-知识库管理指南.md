## 3.36.1 知识分类体系

消息队列知识库按三层组织：系列 → 主题 → 文档。每个知识资产应明确归属，避免重复与遗漏。

| 系列 | 定位 | 代表文档 | 更新频率 |
| ------ | ------ | ---------- | ---------- |
| 01 基础概念 | 概念矩阵与对比分析 | 01-12 专章、01-25 前沿专章 | 随版本发布 |
| 02 场景驱动设计 | 设计原理与选型论证 | 02-12~46 消息专项设计 | 随业务场景扩展 |
| 03 架构与运维 | 落地操作与检查清单 | 03-32~38 治理与运维指南 | 每季度复审 |
| 04 动态系统论 | 系统动力学与演化分析 | 04-01~05 项目特色资产 | 谨慎改动 |
| 资产目录 | 配置、脚本、示例 | config-templates/、scripts/、examples/ | 随代码同步 |

## 3.36.2 目录结构与元数据

每个文档头部保留统一的置信口径与定位声明，尾部保留 `最后更新` 日期。元文档承担导航与状态职责：

- **INDEX.md**：全量导航，新文档必须同步登记。
- **PROJECT_STATUS.md**：唯一权威状态与文件统计。
- **ROADMAP.md**：P0-P4 波次任务与版本追踪基线。
- **CHANGELOG.md**：语义化版本记录。
- **GLOSSARY.md**：术语表，避免同词异义。

```bash
# 检查关键元文档是否存在且非空
cd E:/_src/Mq/topics
for f in INDEX.md PROJECT_STATUS.md ROADMAP.md CHANGELOG.md GLOSSARY.md; do
  if [ -s "$f" ]; then
    echo "✅ $f ($(wc -l < "$f") 行)"
  else
    echo "❌ $f 缺失或为空"
  fi
done
```

## 3.36.3 检索与标签

为提升检索效率，建议在文档内使用统一的标签与关键词。

### 标签命名示例

```markdown
**标签**: #kafka #security #sasl #acl #audit #production
```

### 常用标签分类

| 类别 | 示例标签 |
|------|----------|
| 系统 | #kafka #nats #rabbitmq #mqtt #pulsar #redis-stream |
| 主题 | #security #compliance #governance #multi-tenant #cicd |
| 难度 | #beginner #intermediate #advanced |
| 状态 | #stable #draft #deprecated |

检索方式可结合：

1. **全文搜索**：使用 `grep`/`ripgrep` 或集成搜索引擎（如 Pagefind、Meilisearch）。
2. **分类浏览**：按目录层级导航。
3. **标签筛选**：通过标签云或标签索引快速定位。

## 3.36.4 知识更新与协作

### 多人协作流程

```bash
# 1. 从 main 切出知识更新分支
git checkout -b kb/2026-q4-audit-update

# 2. 批量更新一批相关文档
git add topics/03-架构与运维实践/03-32-*.md
git commit -m "kb(03-32): 增加安全审计脚本与检查清单"

# 3. 更新元文档：INDEX、STATUS、ROADMAP、CHANGELOG
git add topics/INDEX.md topics/PROJECT_STATUS.md topics/ROADMAP.md topics/CHANGELOG.md
git commit -m "meta: 同步批次 18b-3 状态与索引"
```

### 反馈机制

- 在文档末尾或 INDEX.md 中提供反馈入口（Issue 模板、邮箱、即时通讯机器人）。
- 每月汇总反馈，形成知识改进工单。
- 对常见问题补充 FAQ 或独立速查文档。

## 3.36.6 知识库管理检查清单

- [ ] 已建立知识分类体系，新文档归属明确。
- [ ] 新文档已在 INDEX.md 登记，名称与路径符合命名规范。
- [ ] 文档头部保留「置信口径」与「本文档定位」引用块。
- [ ] 文档目录与实际章节一致，无死链。
- [ ] 已按规范添加标签或关键词，便于检索。
- [ ] 已执行 `scripts/knowledge-base-check.sh` 且主要目录与元文档无缺失。
- [ ] 已执行 `scripts/doc-self-check.sh quick` 且无 ERROR。
- [ ] 每季度对知识库进行结构与内容复审，更新 PROJECT_STATUS.md 与 ROADMAP.md【估算】。
- [ ] 已建立用户反馈渠道，并按月汇总处理。
- [ ] 批次更新后已同步更新 CHANGELOG.md，禁止同日版本号膨胀。
