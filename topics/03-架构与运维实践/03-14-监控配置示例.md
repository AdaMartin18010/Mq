## 3.14.2 Grafana仪表板配置

### 关键指标矩阵

| 指标类别 | 具体指标 | 常用 PromQL 示例 |
| ---------- | ---------- | ------------------ |
| **吞吐量** | Producer/Consumer TPS、消息速率、队列/主题深度 | `rate(kafka_server_brokertopicmetrics_messagesinpersec[1m])` |
| **延迟** | P50/P95/P99、端到端延迟、消费Lag | `kafka_consumergroup_lag` |
| **资源** | CPU、内存、磁盘IO、网络带宽 | `100 - (avg by (instance) (irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)` |
| **健康** | 连接数、错误率、副本状态/URP、节点可用 | `kafka_server_replicamanager_underreplicatedpartitions` |

## 3.14.3 告警规则配置

以下规则引用 [`config-templates/prometheus-alert-rules.yml`](../../topics/config-templates/prometheus-alert-rules.yml)。

### Kafka告警规则

```yaml
groups:
  - name: kafka_alerts
    rules:
      - alert: KafkaHighConsumerLag
        expr: max by (consumergroup, topic) (kafka_consumergroup_lag) > 100000
        for: 15m
        labels: { severity: p2 }
        annotations:
          summary: "Kafka Consumer Lag过高"
          runbook: "runbooks/kafka-consumer-lag.md"

      - alert: KafkaUnderReplicatedPartitions
        expr: sum(kafka_server_replicamanager_underreplicatedpartitions) > 0
        for: 10m
        labels: { severity: p1 }
        annotations:
          summary: "Kafka分区副本不足"
          runbook: "runbooks/kafka-urp.md"

      - alert: KafkaDiskPressure
        expr: max by (instance) (1 - node_filesystem_avail_bytes{mountpoint="/var/lib/kafka"}/node_filesystem_size_bytes) > 0.75
        for: 10m
        labels: { severity: p2 }
        annotations:
          summary: "Kafka磁盘使用率超75%"
          runbook: "runbooks/kafka-disk-pressure.md"
```

### NATS告警规则

```yaml
groups:
  - name: nats_alerts
    rules:
      - alert: NATSHighConnections
        expr: max by (server_id) (gnatsd_varz_connections) > 10000
        for: 5m
        labels: { severity: p2 }
        annotations:
          summary: "NATS连接数过高"
          runbook: "runbooks/nats-connections.md"

      - alert: NATSJetStreamConsumerStalled
        expr: max by (stream, consumer) (nats_jetstream_consumer_num_pending) > 10000
        for: 15m
        labels: { severity: p2 }
        annotations:
          summary: "JetStream consumer pending 超1万"
          runbook: "runbooks/nats-pending.md"
```

### RabbitMQ告警规则

```yaml
groups:
  - name: rabbitmq_alerts
    rules:
      - alert: RabbitMQNodeDown
        expr: max by (instance) (rabbitmq_up) == 0
        for: 2m
        labels: { severity: p0 }
        annotations:
          summary: "RabbitMQ节点不可达"
          runbook: "runbooks/rmq-node-down.md"

      - alert: RabbitMQQueueBacklog
        expr: max by (queue) (rabbitmq_queue_messages_ready) > 50000
        for: 15m
        labels: { severity: p2 }
        annotations:
          summary: "队列积压超5万"
          runbook: "runbooks/rmq-backlog.md"

      - alert: RabbitMQMemoryHigh
        expr: max by (instance) (rabbitmq_process_resident_memory_bytes / rabbitmq_resident_memory_limit_bytes) > 0.6
        for: 5m
        labels: { severity: p1 }
        annotations:
          summary: "RabbitMQ内存使用超过高水位"
          runbook: "runbooks/rmq-memory.md"
```

## 3.14.5 监控最佳实践

### 1. 指标选择

- **核心指标**：吞吐量、延迟、错误率
- **资源指标**：CPU、内存、磁盘、网络
- **业务指标**：消息积压、处理速率、消费Lag

### 2. 告警策略

- **严重告警**：立即通知（错误率>1%、节点不可达）
- **警告告警**：延迟通知（延迟>阈值、磁盘>75%）
- **信息告警**：记录日志（资源使用>80%）

### 3. 监控工具

- **Prometheus**：指标收集
- **Grafana**：可视化
- **AlertManager**：告警管理
- **Jaeger/Zipkin**：分布式追踪（与消息链路关联）
