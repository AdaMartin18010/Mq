## 3.17.1 测试环境

| 组件 | 配置 | 数量 | 备注 |

## 3.17.2 测试场景设计

基准测试至少覆盖以下四类场景：

| 场景 | 目标 | 消息大小 | 消息速率 | 测试时长 | 关键指标 |
| ------ | ------ | ---------- | ---------- | ---------- | ---------- |
| **吞吐量测试** | 最大可持续吞吐 | 1KB / 4KB / 16KB | 逐步加压 | 10min | records/sec、MB/sec |
| **延迟测试** | 端到端延迟 | 1KB | 固定 10k msg/s | 5min | P50/P95/P99 延迟 |
| **并发连接测试** | 最大连接数 | 128B | 1 msg/s/conn | 10min | 连接数、内存使用 |
| **耐久性测试** | 故障下数据不丢 | 1KB | 10k msg/s | 15min | 丢消息数、ISR 状态 |

## 3.17.3 测试执行命令

参考 `scripts/performance-benchmark.sh` 与 `scripts/benchmark.sh`。

### Kafka 基准测试

```bash
# 创建测试 Topic，分区数与副本数按生产环境配置
kafka-topics.sh --create --topic benchmark-test \
  --bootstrap-server localhost:9092 \
  --partitions 6 --replication-factor 3

# 运行 Producer 压测
kafka-producer-perf-test.sh \
  --topic benchmark-test \
  --num-records $((10000 * 600)) \
  --record-size 1024 \
  --throughput 10000 \
  --producer-props bootstrap.servers=localhost:9092 \
    acks=all batch.size=32768 linger.ms=10 compression.type=snappy
```

### NATS 基准测试

```bash
# 安装 nats-bench
go install github.com/nats-io/nats.go/examples/nats-bench@latest

# 1 Publisher / 1 Subscriber，100 万条 1KB 消息
nats-bench -s nats://localhost:4222 \
  -np 1 -ns 1 \
  -n 1000000 -ms 1024 -r 100000
```

### RabbitMQ 基准测试

```bash
# 使用 rabbitmq-perf-test
rabbitmq-perf-test -x 1 -y 1 \
  -u "amqp://user:pass@localhost:5672/%2fbenchmark" \
  -s 1024 -r 10000 -z 600
```

## 3.17.5 性能分析

### 瓶颈定位方法

```bash
# 生成性能报告
./scripts/performance-report.sh all benchmark-report-$(date +%Y%m%d).txt

# 关键指标查看
./scripts/metrics.sh
```

### 常见瓶颈与根因

| 瓶颈现象 | 可能根因 | 调优方向 |
| ---------- | ---------- | ---------- |
| 吞吐随分区数增加不再提升 | 网络带宽或磁盘 IO 饱和 | 增加带宽、使用 SSD、调整 batch.size |
| P99 延迟突刺 | GC 停顿或 ISR 收缩 | 调整 JVM、增大 replica.lag.time.max.ms |
| CPU 持续 >80% | 压缩/序列化开销大 | 换 lz4/snappy、使用二进制序列化 |
| 内存持续增长 | 消费滞后或缓存未释放 | 扩容消费者、调整 max.poll.records |
