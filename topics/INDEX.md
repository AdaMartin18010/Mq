## 快速参考

### 技术选型快速决策

- **日志聚合/大数据** → Kafka
- **IoT设备/移动推送** → MQTT
- **微服务通信/边缘计算** → NATS
- **混合场景** → 多协议网关

### 关键指标对比

- **吞吐量**：NATS Core (200万+) > Kafka (100万+) > RabbitMQ (5-20万) > MQTT (10万级)
- **延迟**：NATS Core (30-100μs) < Redis Stream (<1ms) < MQTT (亚毫秒-10ms) < RabbitMQ (1-10ms) < Kafka (5-100ms)
- **运维复杂度**：NATS < MQTT < RabbitMQ < Kafka

- **Apache Kafka**: [官方文档](https://kafka.apache.org/documentation/)（含KRaft模式）
- **MQTT协议**: [OASIS标准](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html)（MQTT 5.0）
- **NATS**: [CNCF项目文档](https://docs.nats.io/)
- **RabbitMQ**: [官方文档](https://www.rabbitmq.com/documentation.html)
- **Redis Streams**: [Redis文档](https://redis.io/docs/data-types/streams/)
