# K2 背书制度 + K3 知识准入与退役（批次 138）

> **地位**：K1 宪章（AI 知识权威宪章）的执行细则。K2 管"权威怎么产生"，K3 管"权威怎么进出"。
> **生效**: 2026-11-18；修订走治理变更批（双签+CHANGELOG）。

## K2 背书制度

### 背书人资格

- **人类背书人**：项目维护者（对本域有直接编辑记录 ≥3 次）；
- **机器背书人**：经回放验证的技能/agent（如 mq-doc-lint + TEST-18 机制），其背书**永远只是第二签**，不可单独升格。

### 升格规则（【论证】→【定理】）

1. 提名：任何协作者可在目标断言处加 `> 升格提名：理由+证据清单`；
2. **双签**：一名人类背书人 + 一名（人或机器）第二签，在 CHANGELOG 记 `endorse: 断言位置+双人+日期`；
3. 生效：标注替换为【定理】，入 decision-evidence.tsv 的 endorser 列；
4. **争议**：两签意见冲突时维持【论证】并加"争议注记"（列双方理由），交用户裁决。

### 禁则

- 机器背书不可单独升格；不可自签（提名人与背书人不得同一主体）；
- 版本事实（发布日期/版本号）永远不可凭背书升格为【定理】——只能引官方源（K1 §2 P0 定义）。

## K3 知识准入与退役

### 准入 checklist（新文档/新断言入库资格，缺一项即退回）

- [ ] 来源：核心事实 ≥2 个独立权威源（官方文档/规范/Jepsen），链接可核验
- [ ] 置信：全文 P3 标注合规；定量声明有来源或【估算】
- [ ] 反例：专章级文档含"边界/陷阱/反例"节；断言级至少一条失效条件
- [ ] 时效：头部时效声明 + 等级（T1-T4）判定
- [ ] 可追溯：互链 ≥2 篇现有资产；新概念入 01-58（或登记挂账）
- [ ] 机器门：E0 自检通过（死链/密度/编号/日期）

### 退役与降级（只降级不删除，保历史可回放）

| 触发 | 处置 |
| ------ | ------ |
| 时效等级过期且复核未更新 | 降级：标题加 `[时效存疑 YYYY-MM]`，正文顶部加注，K1 §3 引用降一级 |
| 被新结论 supersede | 原文保留+顶部"已被 X 取代"指针，INDEX 改指向 |
| 被测试证伪（verified 用例 FAIL 且确认） | **最高优先**：立即标注"已被证伪"，保留原文供溯源，修正结论走 L3 审批 |
| 多源冲突未裁决 | 加"争议存疑"标注（K1 §4 ⑤），禁作 P2 级引用 |

### 执行机制

- 准入 checklist 并入 doc-self-check（E0 WARN 项逐条可机检的优先机检）；
- 退役扫描：季度复核时跑"时效过期清单"（grep 时效声明 vs 当前日期），产出待处置表。
