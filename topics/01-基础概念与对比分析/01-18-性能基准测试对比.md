## 1.18.6 本项目实测基线锚点（L3 已批准）

> **实测口径**：本节为本项目测试环境实测值（非 1.18.2-1.18.5 的公开基准量级整理），数据取自 L3 审批单（Testing/L3-审批单-H4基准转正-2026-11-20.md）签核回灌（批次173/175/178/179/191，2026-11-20~21）。证据锚：results/2026-11-20/h4-benchmark-baseline.md + q178/q179 基线证据 + results/2026-11-21/q191-kafka-federation-baseline.md。

### 测试环境

| 维度 | 值 |
|------|------|
| 虚拟化 | WSL2 podman（宿主 Core Ultra 9 285K 24 核 / 96GB；NATS/RabbitMQ 容器标称 podman WSL2 12vCPU/2GB） |
| Kafka | apache/kafka:4.4.0（KRaft，容器内 exec 官方 perf 工具） |
| NATS | nats-test 容器（nats-server v2.15.3）+ 宿主 Go 客户端（nats.go） |
| RabbitMQ | rabbitmq-test 容器（RabbitMQ 3.13.7）+ 宿主 Go 客户端（amqp091-go） |
| 工具件 | `Testing/benchmark/mq-bench.exe`（nats/rabbit 双模式，git 受控） |

### Kafka producer 基线（A1）

参数（两口径一致）：1KB 消息 / 目标 10000 msg/s（pace 限速）/ 60s / acks=all / batch.size=16384 / linger.ms=10。

**单机锚点**（批次173：kafka-1，KRaft 单节点，bootstrap=localhost:9092 EXTERNAL）：

| 指标 | 值 |
|------|------|
| 稳态吞吐 | 9931.0 records/sec（9.70 MB/sec）（逐 10s 窗口峰值；区间 9318.2~9931.0） |
| 延迟（全窗口） | avg 1.45ms / max 109ms / p50 1ms / p95 3ms / p99 4ms / p99.9 89ms |
| 全窗口均摊 | 3287.66 records/sec（含 ramp-up+尾部 drain，非稳态口径） |

**联邦口径**（批次191：kafka-1/2/3，KRaft 3 节点 quorum=3，bootstrap=kafka-1/2/3:29092 INTERNAL 三节点；拓扑实证=RF3 全分区 ISR=3 + Leader 分布 1/2/3 + api-versions 3 节点无 fenced）：

| 指标 | 值 |
|------|------|
| 稳态吞吐 | 9997.0~10003.0 records/sec（12 窗口；全窗口 9998.000400 records/sec = 9.76 MB/sec） |
| 稳态窗口延迟 | avg 1.1~1.3ms / 窗口 max 4~13ms |
| 全窗口延迟 | avg 2.62ms / max 465ms（ramp-up 窗口）/ p50 1ms / p95 3ms / p99 64ms / p99.9 184ms |

**口径声明**：
1. `--throughput 10000` 为 pace 限速目标，稳态≈目标值=「集群在 acks=all 配置下可稳定承载 10k/s@1KB」的承载力结论，**非集群上限**（上限需无 pace 压测，未做）。
2. 联邦口径 p99 尾延迟（64ms）显著高于单机（4ms）：跨 broker 复制路径 + 全窗口分位数含 ramp-up 污染（ramp-up 窗口 avg 18.5ms/max 465ms）；稳态窗口 max 仅 4~13ms。
3. 联邦重采 topic 为 auto-create（1 分区 RF=1，Leader=3）：producer 路径经 3 节点 bootstrap 分发 + acks=all 语义；RF=3 复制健康由独立探针 topic ISR=3 实证覆盖（批次191 证据 §2/§5）。

### NATS RTT 基线（A2）

串行 request-reply RTT（1KB 请求 / 1B 应答，自然速率，nats.go，批次178）：

| 轮次 | 请求数 | 耗时 | 达成速率 | avg | p50 | p99 | p99.9 | max |
|------|--------|------|----------|-----|-----|-----|-------|-----|
| 1 | 600000 | 201.1s | 2983.6 msg/s | 0.335ms | 0.514ms | 0.932ms | 1.256ms | 44.99ms |
| 2 | 600000 | 214.8s | 2793.0 msg/s | 0.358ms | 0.515ms | 1.003ms | 1.300ms | 44.47ms |

**口径声明**：
1. 达成速率 ≈ 1/avg RTT（单线程串行环的必然关系）；异步发布 paced 10k/s×60s 无错误。
2. 锚点=nats-test 单节点容器（非集群）；工具件 `Testing/benchmark/mq-bench.exe`（nats 双模式 rtt/pub）；环境 podman WSL2 12vCPU/2GB。

### RabbitMQ e2e 基线（A3）

端到端延迟（1KB payload×10k/s×60s，QoS prefetch=500 + 批量 ack，amqp091-go 双 channel，批次179）：

| 指标 | 值 |
|------|------|
| 发布速率（实测） | 10000.0 msg/s（paced，60.0s） |
| 消费收齐 | 600000/600000（零积压，全窗口稳态） |
| e2e avg / p50 | 1.753ms / 0.654ms |
| p95 / p99 / p99.9 | 5.676ms / 6.298ms / 7.339ms |
| max | 24.935ms |

**口径声明**：
1. 锚点=rabbitmq-test 单节点容器（RabbitMQ 3.13.7，非集群）；工具件 `Testing/benchmark/mq-bench.exe`（rabbit 模式，独立 collector goroutine）；环境 podman WSL2 12vCPU/2GB。
2. **诚实边界**：首版 harness 采样停摆缺陷（publish 与采样共享主 goroutine→消费者停摆→积压主导假 p50=31s）已修复；作废数据（5k/2k 两组）保留作缺陷对照（q179_rabbit_bench_{5k,2k}_raw.log）。

**跨系统口径声明**：本节三组基线（Kafka/NATS/RabbitMQ）均为**单机/单节点锚点**，参数口径不统一（Kafka=pace 10k/s 生产者侧、NATS=自然速率串行 RTT、RabbitMQ=pace 10k/s 端到端），**不可横向直接比大小**——仅作为本项目后续基准回归的各自参照锚点。Kafka 联邦口径重采已完成（批次191，见上）。
