## 1.24.5 实践项目

### 推荐项目

1. **日志聚合系统**
   - 使用 Kafka 或 Pulsar
   - 收集应用日志，接入 Flink/Spark 实时分析
   - 参考 [01-31 数据集成与流处理生态分析](./01-31-数据集成与流处理生态分析.md)

2. **IoT 设备接入平台**
   - 使用 MQTT + NATS JetStream
   - 百万级设备模拟、QoS 分级、规则引擎
   - 参考 [01-16 MQTT 5.0新特性深度分析](./01-16-MQTT-5.0新特性深度分析.md)

3. **事件驱动微服务**
   - 使用 NATS 或 RabbitMQ
   - 设计事件契约（AsyncAPI）、死信队列、幂等消费
   - 参考 [02-48 契约设计工作流与事件API治理](../02-场景驱动架构设计/02-48-契约设计工作流与事件API治理.md)

4. **消息平台工程**
   - 构建内部消息平台，包含 Schema、监控、成本治理
   - 参考 [02-59 消息平台工程与内部开发者门户](../02-场景驱动架构设计/02-59-消息平台工程与内部开发者门户.md)
