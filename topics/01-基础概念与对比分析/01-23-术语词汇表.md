## 1.23.1 通用与一致性术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **消息队列** | Message Queue | 异步消息传递系统（本文库统称 MQ） |
| **生产者** | Producer/Publisher | 发送消息的客户端 |
| **消费者** | Consumer/Subscriber | 接收消息的客户端 |
| **主题** | Topic/Subject | 消息分类标识 |
| **队列** | Queue | 消息存储容器（点对点语义） |
| **持久化** | Persistence | 消息持久存储，宕机可恢复 |
| **确认** | Acknowledgment (ACK) | 消费者确认消息已处理 |
| **死信** | Dead Letter | 处理失败且超过重试上限的消息 |
| **投递语义** | Delivery Semantics | at-most-once / at-least-once / exactly-once 三种保证 |
| **幂等性** | Idempotence | 同一消息重复处理结果不变 |
| **顺序保证** | Ordering | 分区/队列内有序 vs 全局有序 |
## 1.23.2 Kafka术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **分区** | Partition | Topic 的分片，有序性单元 |
| **副本** | Replica | 分区副本（Leader + Follower） |
| **ISR** | In-Sync Replicas | 与 Leader 同步的副本集合【定理：Kafka 协议语义】 |
| **偏移量** | Offset | 消息在分区内的位置标识 |
| **消费者组** | Consumer Group | 组内成员分摊分区、互斥消费 |
| **KRaft** | Kafka Raft | 基于 Raft 的内置元数据管理（替代 ZooKeeper） |
| **分层存储/S3 解耦** | Tiered Storage / S3-offload | 热数据本地盘 + 冷数据卸载对象存储；计算层无状态化架构 |

## 1.23.3 MQTT/NATS术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **QoS** | Quality of Service | 0/1/2 三级投递语义【定理：OASIS 规范】 |
| **遗嘱消息** | Last Will | 异常断开时由 broker 代发的消息 |
| **保留消息** | Retained Message | 主题上保留的最后一条消息供新订阅者 |
| **主题别名** | Topic Alias | 用短整数映射长主题名（MQTT 5.0） |
| **原因码** | Reason Code | MQTT 5.0 细粒度 ACK/错误码 |
| **Subject** | Subject | NATS 点分主题，支持 `*`/`>` 通配符 |
| **Queue Group** | Queue Group | 同名组内订阅者负载均衡（每条消息组内一条） |
| **JetStream** | JetStream | NATS 持久化层：Stream/Consumer/KV/ObjectStore |
| **Stream** | Stream | 服务器端消息存储单元 |
| **Consumer** | Consumer | 消费视图（位点/重试/投递策略） |

## 1.23.4 RabbitMQ/Pulsar术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **Exchange** | Exchange | 消息路由器（direct/topic/fanout/headers） |
| **Binding** | Binding | Exchange 到 Queue 的绑定关系 |
| **Virtual Host** | Virtual Host | 逻辑隔离单元（vhost） |
| **Quorum Queue** | Quorum Queue | RabbitMQ 4.x 默认的 Raft 复制队列 |
| **DLX** | Dead Letter Exchange | 死信交换机（`x-dead-letter-exchange`） |
| **Tenant/Namespace** | Tenant/Namespace | Pulsar 多租户两级隔离 |
| **BookKeeper** | Apache BookKeeper | 底层持久化存储（ledger 模型） |
| **Oxia** | Oxia | Pulsar 新一代元数据存储（替代 ZooKeeper） |
| **订阅类型** | Subscription Type | Exclusive/Shared/Failover/Key_Shared |
| **分层存储** | Tiered Storage | Pulsar 冷数据卸载对象存储 |
