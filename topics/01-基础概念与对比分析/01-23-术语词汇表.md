## 1.23.1 通用术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **消息队列** | Message Queue | 异步消息传递系统（本文库统称 MQ） |
| **生产者** | Producer/Publisher | 发送消息的客户端 |
| **消费者** | Consumer/Subscriber | 接收消息的客户端 |
| **主题** | Topic/Subject | 消息分类标识 |
| **队列** | Queue | 消息存储容器（点对点语义） |
| **持久化** | Persistence | 消息持久存储，宕机可恢复 |
| **确认** | Acknowledgment (ACK) | 消费者确认消息已处理 |
| **死信** | Dead Letter | 处理失败且超过重试上限的消息 |
| **背压** | Backpressure | 消费跟不上生产时的流控机制 |
| **扇出** | Fan-out | 一条消息投递给多个订阅者 |

## 1.23.2 可靠性与一致性术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **至多一次** | At-most-once | 可能丢，绝不重（如 NATS Core）【定理：语义定义】 |
| **至少一次** | At-least-once | 可能重，绝不丢（多数持久化系统默认） |
| **恰好一次** | Exactly-once | 不丢不重（需事务/幂等协作实现，成本高） |
| **幂等性** | Idempotence | 同一消息重复处理结果不变 |
| **顺序保证** | Ordering | 分区/队列内有序 vs 全局有序 |
| **重平衡** | Rebalance | 消费者组内分区再分配（Kafka 术语） |

## 1.23.3 Kafka术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **Broker** | Broker | Kafka 服务器节点 |
| **分区** | Partition | Topic 的分片，有序性单元 |
| **副本** | Replica | 分区副本（Leader + Follower） |
| **ISR** | In-Sync Replicas | 与 Leader 同步的副本集合【定理：Kafka 协议语义】 |
| **偏移量** | Offset | 消息在分区内的位置标识 |
| **消费者组** | Consumer Group | 组内成员分摊分区、互斥消费 |
| **KRaft** | Kafka Raft | 基于 Raft 的内置元数据管理（替代 ZooKeeper） |
| **Share Group** | Share Group | KIP-932 队列语义消费组（4.1 预览 → 4.2 GA） |
| **重平衡** | Rebalance | 组成员/分区变化触发的再分配 |
| **数据面/元数据面** | Data/Metadata Plane | 消息传输与控制信息分离的两层 |

## 1.23.4 MQTT术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **Broker** | Broker | MQTT 服务器（协议层无队列语义，broker 实现决定） |
| **QoS** | Quality of Service | 0/1/2 三级投递语义【定理：OASIS 规范】 |
| **遗嘱消息** | Last Will | 异常断开时由 broker 代发的消息 |
| **保留消息** | Retained Message | 主题上保留的最后一条消息供新订阅者 |
| **共享订阅** | Shared Subscription | `$share/{group}/{topic}` 组内负载均衡 |
| **主题别名** | Topic Alias | 用短整数映射长主题名（5.0） |
| **原因码** | Reason Code | 5.0 细粒度 ACK/错误码 |

## 1.23.5 NATS术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **Subject** | Subject | 点分主题，支持 `*`/`>` 通配符 |
| **Queue Group** | Queue Group | 同名组内订阅者负载均衡（每条消息组内一条） |
| **Core NATS** | Core NATS | 无状态内存路由，at-most-once |
| **JetStream** | JetStream | 持久化层：Stream/Consumer/KV/ObjectStore |
| **Stream** | Stream | 服务器端消息存储单元 |
| **Consumer** | Consumer | 消费视图（位点/重试/投递策略） |
| **MaxDeliver** | Max Deliver | 最大投递次数（用尽触发 advisory） |
| **AckWait** | Ack Wait | 未确认重投等待时长 |
| **Consumer Priority Groups** | Consumer Priority Groups | 2.11 引入的优先消费组 |

## 1.23.6 RabbitMQ术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **Exchange** | Exchange | 消息路由器（direct/topic/fanout/headers） |
| **Binding** | Binding | Exchange 到 Queue 的绑定关系 |
| **Routing Key** | Routing Key | 路由键 |
| **Virtual Host** | Virtual Host | 逻辑隔离单元（vhost） |
| **Quorum Queue** | Quorum Queue | 4.x 默认的 Raft 复制队列（替代 classic 镜像） |
| **DLX** | Dead Letter Exchange | 死信交换机（`x-dead-letter-exchange`） |

## 1.23.7 Pulsar术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **Tenant/Namespace** | Tenant/Namespace | 多租户两级隔离 |
| **BookKeeper** | Apache BookKeeper | 底层持久化存储（ledger 模型） |
| **Oxia** | Oxia | 新一代元数据存储（替代 ZooKeeper） |

## 1.23.8 Redis Stream术语

| 术语 | 英文 | 说明 |
| ------ | ------ | ------ |
| **Stream** | Redis Stream | 追加式日志结构（XADD 写入） |
| **消费组** | Consumer Group | XGROUP/XREADGROUP 组内消费 |
| **PEL** | Pending Entries List | 已投递未确认消息列表（死信排查入口） |
| **XACK** | XACK | 确认处理完成（从 PEL 移除） |
