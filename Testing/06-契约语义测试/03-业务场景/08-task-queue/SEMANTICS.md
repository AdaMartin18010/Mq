# 08-task-queue 语义标注

| 维度 | 为什么需要 | 涉及消息 | 验收关注点 |
| ---- | ---- | ---- | ---- |
| 重试退避 | 瞬时故障自愈 | TaskFailedEvent(retryable=true) | 退避序列逐档断言（ASE-006 族，NATS 原生 backoff） |
| 死信 | 毒消息终态 | 重试耗尽任务 | 进 DLQ subject、审计可回放（01-65 三路径之一） |
| 延迟消息 | 定时/延迟任务 | deadline 语义 | 到期触发或逾期拒执行（矩阵 ○/● 格双实现路径） |
| 幂等去重 | 执行副作用不可重复 | TaskEnvelope | 同 taskId 成功执行仅一次（应用层幂等消费者） |

**设计陷阱**：

1. 退避序列必须是**声明式**进契约（backoff: [...]），执行器只读不编——退避策略变更是契约级变更。
2. deadline 语义区分"到期执行"（延迟消息）与"逾期拒执行"（TTL 过滤）两种模式，契约须显式选择。
