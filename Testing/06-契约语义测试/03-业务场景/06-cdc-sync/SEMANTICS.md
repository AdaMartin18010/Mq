# 06-cdc-sync 语义标注

| 维度 | 为什么需要 | 涉及消息 | 验收关注点 |
| ---- | ---- | ---- | ---- |
| 顺序性 | lsn 位点单调是同步正确性根基 | CdcChangeEvent | 同表 lsn 严格递增，乱序=数据腐化（ASE-003 族加强版） |
| 持久化 | 同步管道断点续传 | 全部 | broker 保留期 > 最大恢复窗口（retention 对账） |
| 幂等去重 | 重放窗口内事件重复投递 | CdcChangeEvent | 消费端按 (table,lsn) 幂等；Kafka 源可启用 broker dedup（矩阵 ◐ 格） |
| 背压 | 批量导入洪峰 | CdcChangeEvent | lag 增长速率与恢复时间观测（04 系列故障传播方程衔接） |

**设计陷阱**：

1. op=d 之后同主键 op=c 合法——下游 upsert 语义必须覆盖 delete 痕迹（常见数据腐化源）。
2. schema 变更不可走常规通道静默混入——必须显式事件或头部版本标记（02-57 已述）。
