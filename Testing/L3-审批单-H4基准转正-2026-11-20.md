## 2. 基线数据（Kafka producer，2026-11-20 实测）

- 锚点：kafka-1（apache/kafka:4.4.0，KRaft 单节点，容器内 exec 官方 perf 工具）
- 参数：1KB 消息 / 目标 10000 msg/s / 60s / acks=all / batch.size=16384 / linger.ms=10
- 稳态吞吐：**9931.0 records/sec（9.70 MB/sec）**（逐 10s 窗口峰值；区间 9318.2~9931.0）
- 延迟（全窗口）：avg 1.45 ms / max 109 ms / p50 1 ms / p95 3 ms / p99 4 ms / p99.9 89 ms
- 全窗口均摊：3287.66 records/sec（含 ramp-up+尾部 drain，非稳态口径）
- 环境：WSL2 podman，宿主 Core Ultra 9 285K 24 核 / 96GB
