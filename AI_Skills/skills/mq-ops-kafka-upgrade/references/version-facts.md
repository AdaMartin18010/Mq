# Kafka 版本事实切片（派生自 01-25/ROADMAP，派生日 2026-11-18）

> **时效声明**: 本文事实基于 Kafka 官方发布信息核实至 2026-11；执行升级前必须复核
> [Kafka 官方升级文档](https://kafka.apache.org/documentation/#upgrade) 与目标版本 Release Notes。

## 版本时间线（项目文档基线）

| 版本 | 发布 | 关键事实 | 对升级的影响 |
| ------ | ------ | ---------- | -------------- |
| 3.3.0 | 2022-10 | KRaft 生产就绪 | ZK 集群可规划迁移 |
| 3.5.0 | 2023-06 | ZK 弃用宣告 | 新部署应直接用 KRaft |
| 4.0.0 | 2025-03-18 | **移除 ZooKeeper**；KIP-848 消费者协议 GA | ZK 模式不可直升，须先 KRaft 化 |
| 4.1 | 2025-09-04 | KIP-932 Share Groups（队列语义，Preview） | 预览特性默认关，升级后按需启用 |
| 4.2.0 | 2026-02-17 | KIP-932 GA（生产可用）；KIP-1222/1224/1206/1226/1227 配套 | 队列语义可正式用于任务队列场景 |
| 4.3.0 | 2026-05-22 | KIP-1240/1274/1066/1023/1196 调优与弃用铺垫 | Classic Rebalance 弃用启动，关注框架支持 |
| 4.4.0 | 2026-10-22 | KIP-1191 Share Groups DLQ；KIP-1312 控制器注销 | 队列语义 + 死信队列补齐，建议作为新建集群首选 |

## 升级路径规则【论证】

```text
当前 3.x (ZK模式)  → 先按 01-13/01-25 迁移 KRaft（3.x 内完成）→ 再升 4.x
当前 3.x (KRaft)   → 可滚动直升 4.x（逐 broker，门控 URP=0）
当前 4.x           → 小版本滚动升级（同 major 可降级回滚）
跨 major 降级      → 不支持；走备份恢复（log format 只前进）
```

### 4.x 版本选择速查（截至 2026-11）

| 需求 | 建议版本 | 说明 |
| ------ | -------- | ---- |
| 新建集群 | 4.4.x | 官方当前支持线之首，含 KIP-1191 DLQ |
| 需要队列语义（Share Groups） | ≥ 4.2 | KIP-932 production-ready 起始版本 |
| 运行 4.2 / 4.3 | 规划滚动升级 | 补丁支持以官方"最近三个 release"策略为准 |

## KIP-932 / KIP-848 / KIP-1191 提示

- **KIP-848**（新一代消费者组协议）在 4.0 已 GA，将 Classic Rebalance 的全局停顿改为增量分区转移【论证：官方 KIP 状态，核实至 2026-11】。
- **KIP-932**（Share Groups / Queues for Kafka）提供队列语义：4.0 Early Access → 4.1 Preview → **4.2 GA**；4.4 通过 **KIP-1191** 补齐 Share Groups 死信队列（DLQ）【论证：官方 KIP 状态，核实至 2026-11】。
- 生产启用 Share Groups 前确认客户端版本与监控工具（如 KMinion、Spring Kafka）支持矩阵。
